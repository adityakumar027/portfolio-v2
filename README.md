# Portfolio V2

My second portfolio design: experience, project case files, skills, and contact.

**Live site: [adicrz.vercel.app](https://adicrz.vercel.app/)**

Built with Next.js (via [vinext](https://github.com/cloudflare/vinext)), React 19, Tailwind CSS 4, Three.js (React Three Fiber), GSAP and Framer Motion. Deployed on Vercel from the `fixes-hover` branch; every push to that branch auto-deploys to production.

## Run locally

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

## Commands

- `npm run dev`: start local development
- `npm run build`: build the production output
- `npm test`: build and verify the rendered HTML
- `npm run lint`: lint the codebase
